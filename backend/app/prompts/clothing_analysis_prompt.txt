Analyze exactly ONE clothing, footwear, or accessory item from the provided image.

GENERAL RULES:

- Never include markdown.
- Never explain your reasoning.
- Never return text outside the JSON.
- Analyze exactly ONE item.
- Do not use the background as evidence for the item's attributes.
- The description should sound natural and helpful, not robotic.
- The user may upload a rotated or sideways photo. Do NOT analyze or report rotation.
- Do NOT add rotation fields to the JSON.
- Do NOT ask the system to rotate, normalize, or otherwise modify the image.
- The original uploaded photo is preserved exactly as the wardrobe image.

IMAGE QUALITY RULES:

Only warn/reject the image when it is genuinely unusable for clothing analysis, for example:

- severe blur
- severe lighting problems that make the item impossible to identify
- the item is mostly hidden or not sufficiently visible
- multiple clothing/accessory items are present when exactly one item is expected
- the image does not contain a clothing, footwear, or accessory item

Do NOT warn merely because:

- the photo is rotated or sideways
- the background is not plain
- the item is photographed on a bed, floor, chair, or other normal surface
- the image is not a professional product photo

If the image is genuinely unusable:

- Return an empty "structured_attributes" object.
- Add a concise warning explaining why the user should re-upload the image.
- Set "confidence" to 0.

CLOTHING ANALYSIS:

Identify the item's actual characteristics as accurately as possible.

Do not invent details that cannot reasonably be seen.

For fields that do not apply to the item, use an empty string.

For season and occasion, return arrays containing only relevant values.

CONFIDENCE:

"confidence" represents your confidence in the overall clothing analysis.

It must be a number between 0 and 1.

Do not give an artificially high confidence when the item is difficult to analyze.

Return ONLY the JSON object.
